# KillMontage（キル集メーカー）

**たまったクリップを入れるだけで、キルの場面を自動で見つけて1本にまとめるソフト。**
1分くらいの適当な録画でも、長い録画でもOK。キルの無いクリップは自動で飛ばします。

## 起動
`キル集メーカー起動.bat` をダブルクリック → ゲームを選ぶ（VALORANT / APEX / その他）

## 基本の流れ
1. **① クリップ**: 「フォルダ追加」でクリップのフォルダを選ぶ（サブフォルダも含めて、撮った順に並びます）
2. **▶ キル集を作る** … これだけでOK
3. 好みで: **③ 仕上げ**（色補正・トランジション・タイトル・ゲーム音量）、**④ BGM・音はめ**

## 自動でやること
- キルの場面を探して、その前後だけを切り出す（キルの間の待ち時間はジャンプカット）
- **1つの動画から使うのは1カットだけ**（その動画で一番キルの多い場面）。長い録画でも一番いいところだけ抜き出す
- **同じ場面のダブりを外す**:「○○ - Trim.mp4」と「○○.mp4」は同じ動画として扱い、良い方だけ使う。名前が違っても、キルの瞬間の映像が同じなら1つにまとめる
- キルが見つからないクリップは使わない
- **1キルだけのカットは使わない**（1カットの最低キル数 = 2。② DETECT で変更可）
- 1個目は導入として切らずに見せる（長いクリップなら、一番いい連続キルを最大約20秒）

## BGMは YouTube / Spotify のリンクでもOK（④ MUSIC）
BGM欄に、ファイルの代わりに曲のリンクを貼るだけで使えます。
- **YouTube**（youtube.com / youtu.be / YouTube Music）: 音声を取ってきて使います
- **Spotify**: Spotify の音声は保護されているので、リンクから曲名とアーティスト名を読み取り、**YouTube で同じ曲を探して**使います（どの動画を使ったかはログに出ます）
- 取ってきた曲は `bgm_cache` フォルダに保存されるので、同じリンクなら2回目からすぐ使えます
- 必要なもの: yt-dlp（`pip install yt-dlp`）
- ※ 市販の曲を使ったキル集を公開すると、著作権の申し立てを受けることがあります

## 使うたびに賢くなる（キルバナーの学習・VALORANT）
キル集を作るたびに、使ったクリップの「確認できたキル」のキルバナーの見た目を覚えます（あなたのスキンのバナー）。
- 次からは、覚えたバナーと見比べてキルを確認します（円が無いひし形のバナーなども確認できるようになります）
- キルフィードが映っていない場面でも、覚えたバナーが出ていればキルとして拾います
- 間違えやすい場面（買い物画面・雪・黄色い壁・やられた瞬間）は、覚えたバナーとはほとんど一致しないので拾いません
- 覚えたバナーの数は ② DETECT に表示されます。「学習をリセット」で忘れさせることもできます
- 覚えたバナーの種類が増えると、次の1回だけ解析し直しになります（少し時間がかかります）

## 学習データを友達と共有（② DETECT → SHARE）
- 「自分の学習データを書き出す」→ `.kmlearn` ファイルができるので友達に送る
- 友達の `.kmlearn` を「友達のデータを読み込む」→ お互いの学習が合わさって検出がもっと正確に
- 同じ友達のデータは何度読み込んでも二重になりません（新しいデータで置き換え）
- 書き出すのは自分の学習分だけ（友達から読み込んだ分は含めないので、回し合っても水増しされません）

## 友達に配る
1. `python build_dist.py` を実行 → `dist\KILL-MONTAGE_v1.0.zip` ができる
2. その zip を友達に送る
3. 友達は展開して `Setup.bat` をダブルクリックするだけ（Python / ffmpeg / 必要な部品が無ければ自動で入り、デスクトップにアイコンができる）
- 作者（あなた）の学習データが「同梱」として入っているので、友達は最初から精度の高い状態で使えます
- 更新するときも新しい zip の `Setup.bat` を実行するだけ。学習データ・設定は残ります

## どのカットを優先するか（評価）
1. **1ラウンドのキル数**が多いほど高い（3キル・4キル・ACE はボーナス）
2. **短い時間に連続で倒す**ほど高い（3秒以内の連続キルを大きく加点、5秒以内も少し加点）

| 例 | 評価 |
|---|---|
| 2キル（間が空いている） | 20 |
| 2キル（連続） | 32 |
| 3秒で3キル | 64 |
| 4キル（ばらばら） | 69 |
| 4キル（うち2キルが3秒以内） | 77 |
| ACE | 104〜 |

1つの動画から選ぶ1カット、BGMに収めるときに残すカット、盛り上がりに合わせるカット、締めのカット、全部この評価で決めます。
- だんだんテンポを上げて、一番キルの多いカットで締める
- ゲーム音の大きさをクリップごとにそろえる

## ゲーム別プリセット
| | VALORANT | APEX LEGENDS |
|---|---|---|
| 狙う音 | キルバナー音（音程のはっきりした高音） | ダウン/キル/アーマー割れの鋭い音 |
| テンポ | キルの間を詰めて約1〜1.5秒ごとにキル | 撃ち合いを少し長めに残す |
| 連続キル | 15秒以内をまとめる（マルチキル・ACE） | 12秒以内をまとめる（部隊壊滅） |
| 仕上げ | 鮮やか | スライド + シネマ |

連続キルは優先してピックアップされます。

## BGMの長さに合わせる（④ BGM・音はめ、標準でON）
クリップがたくさんあっても、BGMの長さに収まるように**質の高いカットだけ**を選びます。
- 目標の長さ = BGMの長さ − 5秒（2:30の曲なら 2:25 あたりで終わる）。開始位置や速度変更も計算に入れます。何秒前に終わるかは変えられます。
- 質の高さ = キル数。3キル以上・4キル以上・5キル（ACE）にはボーナスを付けます。同じ点数なら短いカットを優先します。
- 選んだカットは元の順番のまま並べます（導入・テンポ上げ・締めはそのあとでかけます）。
- 全部入れても収まるときは、全部使います。
- 音はめで少し長くなっても、目標の長さを超えたらそこでフェードアウトして終わります。

## 構成（標準でON）
- **1個目のクリップは導入**: 切らずに見せます。20秒以内のクリップなら丸ごと、長いクリップなら最初のキルから約20秒ぶん。導入にしたいクリップをリストの一番上に置いてください。シャッフルしても先頭のままです。
- **だんだんテンポを上げる**: 2本目は各キルの前後を1.6倍ゆったり見せて、最後のクリップに向けて設定値まで詰めていきます。
- **キルが見つからないクリップは使わない**
- **締めは一番キルの多いカット**: 一番キルの多いカットを最後に回して締めます。テンポは並び順が決まってから割り当てるので、締めが一番速いテンポになります。

## 参考動画から学ぶ（② キル検出 → 構成）
好きなキル集（他の人の動画でもOK、複数選べます）を選ぶと、次のことを測って設定に反映します。
- ショットの長さ（中央値）→ 各キルの前後に何秒残すか
- 白フラッシュの量 → トランジションをフラッシュにするか、ただのカットにするか
- カットが拍に合っている割合（偶然の場合と比べる）→ 音はめするか
- 最初のカットまでの長さ → 1個目を導入にするか

学んだ設定はゲームごとに保存されて、次にそのゲームを選んだときも自動で使われます。
※ キルの位置は参考動画からは測りません（画面をトリミングしている動画が多く、キルフィードが映らないため）。

## APEX: キルフィードで検出（標準でON）
右上のキルフィードで、自分の名前は黄緑で表示されます（味方は青緑、ほかの人は白）。
「自分の名前 → 銃アイコン/[失血死] → 相手の名前」の行が新しく出た瞬間を、自分のダウン/キルとして検出します。
- 自分がやられた行（自分の名前が右側）、「○○が3キルで新しいキルリーダー」などのお知らせ、観戦中のカードは数えません。
- 名前を変えても大丈夫です（色で見ているので）。
- 長い録画（試合まるごと）でもOK。13分の録画で約45秒で解析できます。

## VALORANT: キルフィード + キルバナーで検出（標準でON）
1. **キルフィード**（右上）: 自分のキルの行は「黄色いバー → 自分の顔 → 青緑の『自分』プレート」の並びになります。この行が新しく増えた瞬間を探します。
   - 自分が**やられた**行（黄色い印が右端）は数えません
   - 黄色い壁・コンテナ・ケーブルなどは行の形になっていないので数えません
   - 動画の最初から出ている行（録画前のキル）は数えません
2. **キルバナー**（照準の下）: 自分がキルすると必ず出るバナーで確認します。キルの直後1.2秒にバナーが出ていないものは外します。
   - バナーの真ん中の絵はスキンごとに違いますが、まわりの円は共通なので、円（細く明るい線の輪）で判定します。白・水色・赤など色が違っても大丈夫です
   - ひし形などの円が無いバナーや、編集で画面が切り取られた動画など、バナーが一度も見えない動画では、確認を飛ばしてキルフィードの結果を使います
- 時刻は、キル音の立ち上がりに合わせて自動で微調整します。

## キルの間を詰める（ジャンプカット）
1つのクリップの中でキルとキルの間が空いていたら、その間の移動・待ち時間を自動でカットします。
- 1キル目は「最初のキル前」の秒数、2キル目以降は「各キルの前」の秒数だけ前から見せます。
- 各キルの後は「各キルの後」の秒数だけ残して、次のキルへ飛びます。
- 例：VALORANTのACE（30秒近くかかったラウンド）→ 約8秒（1キルあたり約1.3秒）
- テンポが速すぎる → 「各キルの前」を伸ばす。もっと速く → 短くする。

| | VALORANT | APEX |
|---|---|---|
| 最初のキル前 | 1.5秒 | 2.5秒 |
| 各キルの前 / 後 | 1.0秒 / 0.35秒 | 1.6秒 / 0.5秒 |
| 連続キル判定 | 15秒（ラウンド中のキルをまとめる） | 12秒 |

## キル音登録（精度が大きく上がる）
1. 「② キル検出」→「クリップから登録…」
2. 「候補を探す」→ 候補をダブルクリックで試聴
3. キル音だったら「✔ 登録」（2〜3個登録すると安定）

- 登録すると、その音に似ている場所だけを探します。銃声と区別しやすくなります。
- VALORANTは連続キルでキル音が高くなりますが、少しの音程の違いには自動で対応します。
- VALORANTはスキンでキルバナー音が変わるので、使うスキンごとに登録してください。
- APEXはダウン音とキル確定音の両方を登録するのがおすすめです。
- 「① クリップ」の「検出テスト」で、どこが検出されるかを書き出す前に確認できます。

## BGM加工
- **ピッチ**（±12半音）、**速度**（50〜200%）は別々に変えられます。ピッチだけ上げてテンポはそのまま、といった調整ができます。
- 低音ブースト、リバーブ、開始位置、フェードイン/アウト
- プリセット: Nightcore / Slowed / Slowed+Reverb / 低音ブースト
- 「▶ 試聴」で加工後の音を20秒確認できます

## 盛り上がりにいいキルを合わせる（④ MUSIC → BEAT SYNC、音はめON時）
曲が落ち着いてから一気に盛り上がる瞬間（サビの入り・ドロップ）を自動で見つけて、そこに**質の高いカットの決めの1キル**を合わせます。
- 「盛り上がりを解析」を押すと、曲の音量の流れと、見つけた盛り上がりの位置（▼）がグラフで見られます。
- 一番大きい盛り上がりには一番キルの多いカット、2番目には2番目…と割り当てます（最大4か所）。
- そこまでのすき間は、キル前の助走を長めに見せる → 次のカットを短く詰める → 前のカットの続きの映像、の順で埋めます。映像を止めて引き延ばすことはしません（どうしても届かない盛り上がりには合わせません）。
- カットが少なくて動画が短いときは、動画の長さの中にある盛り上がりだけを使います。

## 音はめ
- 曲のBPMと拍の位置を自動で検出します（加工後のテンポで検出）。
- 各カットの長さを調整して、**キルの瞬間（スロー＋フラッシュ）が拍ぴったり**に来るようにします。カットの切り替えも拍の頭に合わせます。
- 切り替え: 1拍 / 2拍 / 1小節ごと
- 「拍ごとに画面を光らせる」で拍に合わせて画面が軽く光ります
- BPMが倍や半分で検出されたら、BPMを直接入力してください。全体が早い/遅いと感じたら「タイミング補正」で調整してください。

## コマンドでも使える
```
python killmontage.py a.mp4 b.mp4 -o out.mp4 --game valorant --bgm song.mp3 --beat --pitch 2 --speed 110
```
